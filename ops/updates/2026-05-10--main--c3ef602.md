## Summary

Two small UI fixes prompted by a screenshot from the live site.

**1. Preview postcard sizing.** On a wide viewport, the postcard
inside Step 5's `.bb-preview-layout` was rendering at its full 4:5
aspect ratio against the grid's 1fr track, ending up ~1000x1250 px.
That pushed the sidebar's Generate / Send buttons off the right edge
and the postcard itself off the top/bottom of the viewport.

Fix in `app/globals.css`:

- `.bb-postcard.is-preview` capped at `max-height: min(70vh, 640px)`
  with `width: auto` and centered via `align-self / justify-self:
  center`. Aspect-ratio-driven width now scales down so the postcard
  always fits the viewport.
- `.bb-preview-layout` columns tightened to `minmax(260px, 340px)`
  for the sidebar (was 280-360) and `align-items: start` so the
  sidebar doesn't stretch unnecessarily.
- Sticker buttons inside the sidebar get `max-width: 100%; white-space:
  normal; word-break: normal` so a wide button label wraps instead of
  overflowing horizontally.
- New `@media (max-width: 880px)` collapses the layout to a single
  column with a smaller postcard cap, so the Preview step degrades
  gracefully on narrow viewports.

**2. Drop misleading `style: "sing-along"` default.** `blankFriend()`
in `app/page.tsx` defaulted `style: "sing-along"` — a leftover from
the legacy 4-step wizard's style grid. `buildSimpleDraftRequest`
hardcodes `voiceMode: "narrate"` regardless of `style`, so generation
was never actually defaulted to song mode. But the dashboard postcard
meta was rendering "Style: sing-along" which read as if it WAS. Switch
default to `""` so the meta drops out and there's no confusion.

User-facing answer: generation defaults to **narrate** with the
saved/cloned ElevenLabs voice (or stock narrator if no voice setup).
The user can pick a Music chip on the Prompt step which folds a vibe
directive into the prompt — but it does NOT auto-switch voiceMode to
song. To get song mode end-to-end we'd need to add a voice-mode chip
back; deferred.

## Blockers Or Risks

- The `:has(.bb-preview-layout)` selector on `.bb-step-panel` (still
  in place from 5e1f218) requires Chrome 105+ / Safari 15.4+ /
  Firefox 121+. Older browsers fall back to the 720 px panel; the
  new postcard max-height cap still applies, so it'll just look
  slightly cramped, not broken.
- The single-column fallback under 880 px stacks the postcard above
  the sidebar; if the user is mid-generation on a small viewport
  the spinner sits above the Generate button rather than next to it.
  Acceptable for now.
