## Summary

First HolidayBot feature: Mother's Day studio at `/mothers-day` plus a
"Try our other cards" rail on the BirthdayBot dashboard.

The pipeline is shared. An optional `Occasion` field (`"birthday" |
"mothers-day"`) on `DraftRequest` parameterizes:

- The OpenAI plan call: a second system message overrides the
  birthday-themed static instructions when occasion ≠ birthday. The
  static prompt stays cacheable; cache key now suffixed with occasion
  so each occasion gets its own warm cache.

  (no party tropes for Mother's Day). Occasion-specific negative-prompt
  extras suppress cake/candles/balloons/confetti.
- Voice-over text: greeting flipped from "Happy birthday" to
  "Happy Mother's Day" with the cleanup regex aware of either form.
- Mock plan + caption fallbacks: mom-themed copy when offline.

Frontend:
- `app/page.tsx` Dashboard now renders `<HolidayRail />` listing
  Mother's Day (live) plus 7 coming-soon occasions.
- `app/mothers-day/page.tsx` is a slim 3-step studio (Photo+name+swatch
  / Prompt+voice / Brief & generate) reusing `studioApi` and the same
  `birthdaybot:new-ui-voice-setup` localStorage key so one voice clone
  serves every occasion.
