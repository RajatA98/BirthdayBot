## Summary

Two related changes that landed together because the user ran into the
production failure while reviewing the new wizard flow.

**Routing fix.** The Brief step in the wizard was returning the literal
"Request failed." which traces to `lib/client-api.ts:parseJson` — the
generic fallback used when the response has no parseable body. Root cause
was Vercel's default 10s function timeout on the Hobby/default tier:
`/api/plan` runs two sequential OpenAI calls (analyzePhoto vision +
planBirthdayVideo structured-output), and the Lambda was being killed
mid-flight, leaving the client with no body to read.

- Added `export const maxDuration = 60` to `/api/plan`, `/api/generate`,
  and `/api/jobs/check`. (Vercel allows up to 60s on serverless functions
  when configured per-route via Next 15 segment config.)
- Rewrote `parseJson` so non-OK responses surface the actual status code
  + statusText plus a tailored hint (504/408 → "Try a smaller photo or
  try again.", 413 → "The photo is too large. Try one under 4 MB.").
  Generic fallback retained only for genuinely empty responses.

**Prompt suggestion + accent chip palette.** Users had no scaffolding on
the Prompt step beyond a bare textarea.

- New `/api/suggest-prompt` POST route + `lib/tools/suggest-prompt.ts`
  helper. Takes `{ photoDataUrl, photoName?, birthdayName? }`, reuses
  the existing `analyzePhoto` vision call, then runs a single small
  Responses API call to draft one first-person sentence the user could
  send as their prompt. Fallbacks to a templated sentence when OpenAI is
  unreachable, so the route never breaks the flow.
- StepPrompt now renders:
  - A "Suggest from your photo" button below the textarea. Result
    appears as a soft pill with a "Use this" action that copies the
    suggestion into the textarea.
  - Four category chip rows under the suggest pill: **Accents**
    (multi-select), **Vibe** (single-select), **Setting** (single,
    optional), **Music** (single, optional). Every category ends with
    an "Other…" chip that toggles a free-form 80-char input.
  - Music chip is a vibe directive only — it does NOT auto-switch
    `voiceMode` to song. Voice mode still comes from the voice setup
    card on the same step.
- `buildSimpleDraftRequest` folds selected chips + free-form values
  into a trailing structured paragraph appended to the user prompt
  before the brief is built (e.g. "Accents: Cake & candles, Balloons.
  Vibe: warm & heartfelt. Setting: rooftop golden hour. Music: indie.").

## Blockers Or Risks

- The `/api/plan` 60s ceiling is a Vercel hard limit on Hobby; on Pro
  it goes to 300s. If we ever change provider or photo size grows
  meaningfully, we may need to push this higher again or break planning
  into two endpoints (analyzePhoto first, then plan separately).
- The `parseJson` rewrite changes the surfaced error string. Any caller
  that does string-matching on `"Request failed."` would break — none
  exist in the repo at the moment. Worth noting if a future test
  asserts on the message.
- `OPENAI_PLAN_MODEL` defaults to `gpt-4.1-mini` in three places
  (analyze-photo, plan-birthday-video, suggest-prompt). If we want to
  move models we should centralize that env-var read in one util.
