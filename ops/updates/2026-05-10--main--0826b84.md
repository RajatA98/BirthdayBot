## Summary

Sparkly Mother's Day overlay. The result postcard's
"Happy Mother's Day, {Name}" was a flat black-on-white box; now it's:

- Translucent rose-tinted glass panel with `backdrop-filter: blur`
  so the underlying video shows through, plus a soft rose-glow rim.
- Rose-gold + champagne gradient text with a 3.4s shimmer animation.
- Four star sparkles (✦ / ✧) at the corners on a staggered 2.4s
  twinkle (scale + 15° rotation).
- `@media (prefers-reduced-motion: reduce)` opts out of the animations.

CSS-only, no JS runtime cost. JSX additions are four decorative
`<span aria-hidden>` siblings under the same `.md-overlay`.

## Blockers Or Risks

- `backdrop-filter` is unsupported on Firefox < 103 and old iOS. On
  those browsers the panel falls back to the gradient-only background,
  which is still readable but loses the glass blur.
- The sparkles are decorative on the HTML overlay (CSS layer). They
  do NOT appear in the downloaded MP4 — that's pixel data from the
  fal+ffmpeg pipeline, no DOM. Baking the title + sparkles into the
  MP4 would require an ffmpeg drawtext pass.

## Next Context

If we want the sparkle to also appear in the downloaded video,
add a drawtext + overlay step in `lib/tools/mux-voice-over.ts` to
render the title via ffmpeg (gold gradient via `geq` color filter
is hard; easier path is a PNG title card from canvas server-side
and `overlay=` into the video).

Same pattern can be reused for the next holiday by:
1. Adding a `<HolidayName>-overlay-sparkle` modifier class.
2. Tweaking the gradient color stops (rose-gold for mom → deep red
   for Valentine's, royal blue/silver for Father's Day, etc.).
