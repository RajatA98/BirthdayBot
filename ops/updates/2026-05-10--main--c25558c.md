## Summary

Fix the perceived "double audio in preview, no voice in download" bug.

Two compounding causes:

1. `next.config.ts` only bundled `ffmpeg-static` for `/api/generate` and
   a non-existent `/api/jobs/[jobId]` route. The mux step actually runs
   inside `/api/jobs/check` (called from the client-side poll), so on
   Vercel the binary was missing in that Lambda. `getFfmpegPath()`
   returned a path that didn't exist, mux threw, `resolveFinalVideoUrl`
   fell back to the raw fal MP4 plus a separate `<audio>` overlay for
   the ElevenLabs voice. Preview = fal audio + ElevenLabs together,
   download = raw fal MP4 only. Fix: include ffmpeg with `/api/jobs/check`.

2. `buildFalInput` was setting `generate_audio: true` on kling v3 when
   no voice sample was uploaded — fal then generated its own celebratory
   audio. Always silent fal MP4 now, since ElevenLabs always carries the
   voice (TTS, S2S Voice Changer, or sung song).

## Blockers Or Risks

- If Vercel function bundle exceeds 50 MB, ffmpeg-static (~25 MB) under
  `/api/jobs/check` might bump us close. Monitor build size on the next
  deploy. If it overshoots, alternatives are `@ffmpeg-installer/ffmpeg`
  (smaller binary), an external transcoding service, or invoking fal's
  own audio-mux endpoint.
- Test for `generate_audio: true` on advanced/v3 endpoint was inverted
  to assert the property is absent; the negative_prompt + cfg_scale
  asserts on the same test were preserved.

## Next Context

After this push, the polling endpoint should successfully mux on Vercel
and `JobRecord.videoUrl` will be the muxed URL with voice baked in. The
`<audio>` overlay element will only render in failure cases (which
should now be rare). The download link uses `job.videoUrl` directly, so
download = muxed video automatically.

The HTML "Happy Birthday {Name}" overlay is still purely a CSS layer in
`ResultVideo` and will NOT appear in the downloaded MP4. Baking it in
would require an ffmpeg drawtext pass or a server-side text-render
overlay — not done here, deferred unless requested.
