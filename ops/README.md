# Ops Folder

This folder stores shared working context for humans and Codex instances collaborating in this repository.

Files:

- `TEAM_CONTEXT.md`: Stable repo context, conventions, and decisions that should remain true across sessions.
- `CODEX_UPDATES.md`: Append-only log of meaningful progress, blockers, and next-step notes.
- `updates/`: Push-by-push branch sync notes generated for review before pushing.

Workflow:

- Read `TEAM_CONTEXT.md` before substantial work.
- Append short, dated notes to `CODEX_UPDATES.md` after major phases.
- Review `updates/*.md` files after pulling, merging, rebasing, or switching branches.
